# دفترساز

وبلاگ شخصی مسعود — با گیت‌هاب پیجز و جکیل ساخته شده است.
آدرس وبلاگ: https://daftarsaz.github.io

## اضافه کردن یک نوشته تازه

۱. در همین مخزن، وارد پوشهٔ `_posts` شوید.
۲. روی «Add file» و بعد «Create new file» کلیک کنید.
۳. نام فایل را به این شکل بگذارید: `سال-ماه-روز-نام-انگلیسی.md` — مثلاً `2026-11-20-my-first-note.md` (تاریخ باید میلادی و به همین قالب باشد).
۴. بالای فایل، این چند خط را بنویسید (عنوان و تاریخ فارسی را عوض کنید):

```
---
layout: post
title: عنوان نوشته
fa_date: ۲۶ آبان ۱۴۰۵
tag: برچسب
summary: یک جمله خلاصه از نوشته
---
```

۵. زیر آن خط‌ها، متن نوشته را بنویسید.
۶. روی «Commit changes» کلیک کنید. یکی دو دقیقه بعد، نوشته در وبلاگ دیده می‌شود.

## ویرایش یک نوشته

روی فایل نوشته در پوشهٔ `_posts` کلیک کنید، بعد روی مداد (✏️) بزنید، متن را عوض کنید و «Commit changes» را بزنید.
